# Flights tracker – live flight radar

**Open the radar:** https://linushemingstam2-ux.github.io/Flights-tracker/

A Flightradar24-style map of aircraft flying right now, using free community ADS-B networks
(adsb.lol, airplanes.live, adsb.fi, OpenSky). Tap any plane to see its details.

This repository is the published website. The full project, including the optional server,
lives in the private `Tracker` repository; these files are its `public/` folder.
